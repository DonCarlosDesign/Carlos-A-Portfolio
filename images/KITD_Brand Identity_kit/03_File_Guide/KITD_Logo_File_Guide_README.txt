01 -- THE SIX LOGO VERSIONS
----------------------------------------

01 -- PRIMARY DARK -- CORAL/ORANGE
White logo + coral to orange gradient -- transparent background
USE: Your main logo. Use this on any dark surface.
EXAMPLES: Dark website, dark social posts, dark ad backgrounds,
pitch decks, dark merch mockups.
FILES: AI, SVG, PDF, PNG @2x, PNG @3x

02 -- PRIMARY LIGHT -- CORAL/ORANGE
Dark logo + coral to orange gradient -- transparent background
USE: Use this on any white or light surface.
EXAMPLES: White website sections, light social posts, documents,
invoices, email signature, light merch.
FILES: AI, SVG, PDF, PNG @2x, PNG @3x

03 -- SECONDARY DARK -- PINK/YELLOW
White logo + flamingo pink to canary yellow gradient -- transparent background
USE: Alternate colorway on dark surfaces. Same usage as Primary Dark.
EXAMPLES: Dark social posts, dark ads, dark website,
any dark surface where the alternate gradient is preferred.
FILES: AI, SVG, PDF, PNG @2x, PNG @3x

04 -- SECONDARY LIGHT -- PINK/YELLOW
Dark logo + flamingo pink to canary yellow gradient -- transparent background
USE: Alternate colorway on light surfaces. Same usage as Primary Light.
EXAMPLES: White website sections, light social posts,
light merch, documents.
FILES: AI, SVG, PDF, PNG @2x, PNG @3x

05 -- ONE COLOR BLACK
Black logo, 50% grey I for separation -- transparent background
USE: For any vendor who prints or embroiders in one color.
EXAMPLES: Embroidery, screen printing, laser engraving,
stamping, black and white printing.
NOTE: If your vendor cannot reproduce the grey I,
request a full solid black version from your designer.
FILES: SVG, PDF, PNG @2x

06 -- ONE COLOR WHITE
White logo, 50% light grey I for separation -- transparent background
USE: For printing on dark colored merchandise or packaging.
EXAMPLES: Dark hats, dark shirts, dark packaging, dark stickers.
NOTE: If your vendor cannot reproduce the grey I,
request a full solid white version from your designer.
FILES: SVG, PDF, PNG @2x


----------------------------------------
02 -- FILE FORMAT GUIDE
----------------------------------------

.PNG -- Use for everything digital
Social media, ads, website, email, presentations, crowdfunding
page, Canva, Google Slides. Always use @2x or @3x for best quality.

.SVG -- Give to your web developer
For website and app builds. Scales to any size without getting
blurry. Hand this file directly to whoever builds your site.

.PDF -- Use for all print vendors
Business cards, packaging, banners, signage, stickers.
Send this to any printer. Highest quality for professional printing.

.AI -- Master source file -- keep safe
Do not open unless you have Adobe Illustrator. Back this up
somewhere safe. If you ever need the logo updated, a designer
will need this file.

04 -- BRAND COLORS
----------------------------------------

Use these exact codes in any tool, template, or platform.

Coral           #FF5F6D     RGB 255/95/109      Gradient start, accents
Burnt Orange    #FF8C00     RGB 255/140/0       Gradient end, CTAs
Onyx            #1E1E1E     RGB 30/30/30        Primary dark background
Charcoal        #1A1A1A     RGB 26/26/26        Logo dark, body text
Off White       #F8F8F8     RGB 248/248/248     Primary light background
White           #FFFFFF     RGB 255/255/255     Logo on dark, text on dark

PRO TIP: In Canva, use the hex codes above under Brand Colors.
In Instagram, paste them into any color picker.

----------------------------------------

All three fonts are free. Download and install them so any

anything bold and commanding.

02 -- Inter -- Body Copy
Use for: Product descriptions, website paragraphs,
captions, all long-form text anywhere.
Download free: fonts.google.com -- search Inter

03 -- Space Grotesk -- Labels, Stats & Eyebrows
Use for: Section labels, product specs, data points,
legal text, UI elements, small captions.
Download free: fonts.google.com -- search Space Grotesk
